# نموذج تقرير فحص السيارة — فزاع

## ملفات المشروع
- `index.html`: بنية الصفحة العربية وحقول بيانات التقرير.
- `app.css`: الألوان والتنسيق المتجاوب وقواعد الطباعة على A4.
- `app.js`: نقاط الفحص الـ29، حالات الفحص، حفظ المسودة المحلية، التوقيع، وتجهيز نسخة الطباعة.
- `fazza-logo.png` و`wa-qr.svg`: شعار فزاع ورمز واتساب المستخدمان في الصفحة والتقرير.

## التشغيل على الكمبيوتر
ضع الملفات الستة في مجلد واحد. لتشغيله محلياً، افتح Terminal داخل المجلد وشغّل:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`. عند الضغط على «حفظ PDF / طباعة»، اختر «حفظ كملف PDF» من نافذة الطباعة في المتصفح.

## تعديل النموذج
عدّل النصوص والحقول في `index.html`. غيّر الهوية والأبعاد في `app.css`، وتجد لون العلامة الأساسي ضمن متغير `--orange`. قائمة نقاط الفحص والحالات موجودة أعلى `app.js` داخل `points` و`statuses`.

المسودة تُحفظ في التخزين المحلي للمتصفح على الجهاز الحالي، ولا تُرسل إلى خادم. مشاركة مجلد المشروع عبر Google Drive لا تشغّل تطبيق HTML داخل معاينة Drive؛ استخدم استضافة صفحات ويب، أو انقل الملفات إلى مشروع Google Apps Script إذا أردت رابط تطبيق من Google.
